## 注意事项

- **僵尸实例**：若之前有未退干净的 dsh-desktop 进程，`open` 会因单实例锁聚焦旧实例而非新启（表现为"应用在但 dsh 没起/日志缺失"）。排查用 `pgrep -fl dsh-desktop` + `pkill -f dsh-desktop`。
- 浏览器兜底按钮 / dsh UI 内部功能（agent 会话、API key 配置）需人工在窗口内操作验证，未自动化。
